# CodeExam sample content

This folder ships with CodeExam's first-run index. It holds two **distinct**
kinds of content — keep them straight:

## `hunch/` — a synthetic demo app (not real)

**Hunch™ by Overfit Labs** is a small, *synthetic* AI app written by Claude
(Anthropic) for the CodeExam demo: a parody "explainable AI" that commits to a
verdict, then manufactures a convincing post-hoc rationalization for it. Its job
is to exercise CodeExam's AI/ML detectors on honest, real-marker usage —
`--llm-calls`, `--chains`, `--tools`, `--prompts`, `--inference`, `--embeddings`,
and `--pipelines` all light up cleanly. See [`hunch/README.md`](hunch/README.md).
One file, `hunch/app/demo.js`, actually runs (needs `npm install` +
`ANTHROPIC_API_KEY`).

## `harnesses/` — real CodeExam output

The `*.py` files under [`harnesses/`](harnesses/) are **real** instrumentation
harnesses that CodeExam generated by static analysis of actual PyTorch model
classes (DeepseekV3 MoE, Res2Net, an interpretable net). They are a preview of
the forthcoming `--emit-harness` feature (#95), included so you can see what CE
produces. Each carries an auto-generated header explaining its provenance — CE
emits them mechanically but never runs them; you do, after supplying a model and
a sample input.

They are **not** part of Hunch — they're authentic CE artifacts, kept separate
so the synthetic-vs-real line stays clear.
