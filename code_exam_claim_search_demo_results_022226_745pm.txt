 USER MESSAGE (the patent claim text)
========================================================================
1. A method of establishing a secure communication connection
through a computer network, the method comprising:

  (a) initializing a cryptographic context by creating a security
      protocol object configured with a minimum protocol version
      and loading one or more certificate authority credentials;

  (b) negotiating cipher parameters between a client device and
      a server device, wherein negotiating comprises selecting a
      cipher suite from a set of supported cipher suites based on
      a minimum key length requirement;

  (c) performing a handshake protocol exchange between the client
      device and the server device to establish session keys;

  (d) verifying a certificate chain presented by the server device,
      wherein verifying comprises:
        (i)   validating that a hostname of the server device matches
              a subject alternative name or common name in a server
              certificate;
        (ii)  checking that the server certificate has not expired;
        (iii) confirming that key usage extensions in the server
              certificate permit server authentication; and

  (e) transmitting application data over an encrypted channel using
      the established session keys, wherein all data transmitted
      between the client device and the server device is encrypted
      using the negotiated cipher suite.
